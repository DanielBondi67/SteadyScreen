# SteadyScreen

An experimental Android app that aims to stabilize screen content during bumpy
rides, making reading easier. It may also benefit people with Parkinson’s disease;
that possibility remains untested.

Physical tests so far have not been very promising.

## Build and run

Open the project in Android Studio with Android SDK 36 installed, then run it on
an Android 14+ device. To build the debug APK from the command line:

```bash
./gradlew assembleDebug
```
